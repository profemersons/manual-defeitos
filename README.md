# LAB.DIAG — Apostila Interativa de Falhas de Hardware

Site estático, mobile-first e pronto para GitHub Pages.

## Arquivos
- `index.html` — estrutura e conteúdo
- `style.css` — visual responsivo
- `script.js` — mapa de sintomas, simulador e quiz

## Como publicar
1. Crie um repositório no GitHub.
2. Coloque os três arquivos na raiz.
3. Vá em Settings → Pages.
4. Selecione a branch principal e a pasta `/root`.
5. Publique.

## Conceito pedagógico
O material foi reorganizado a partir do conteúdo fornecido para priorizar:
**sintoma → causas → investigação → teste → interpretação → solução → validação → documentação**.

Os cenários e procedimentos devem sempre ser adaptados ao equipamento real e à documentação do fabricante.
